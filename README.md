# Eventix - Sistema de Gestión de Boletería y Ventas

**Integrante:** Nicolas Cordoba Ramirez

## 📄 Descripción del Dominio
Eventix es un sistema transaccional diseñado para centralizar y automatizar el proceso de comercialización de boletería para eventos masivos. La plataforma gestiona la infraestructura de recintos, la programación de eventos y las boleterías físicas o virtuales asociadas a cada función. Además, permite procesar órdenes de compra en tiempo real vinculando tipos de boletos con sus correspondientes transacciones monetarias. El sistema garantiza la consistencia e integridad de las ventas mediante un control estricto de disponibilidad y liquidación de pagos.
